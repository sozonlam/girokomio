# Εκκλησιαστικό Γηροκομείο Λέρου

Ελαφριά, στατική ιστοσελίδα χωρίς build system ή πακέτα JavaScript. Το περιεχόμενο φορτώνεται από αρχεία JSON και επεξεργάζεται από το Decap CMS στη διαδρομή `/admin/`.

## Τοπική προβολή

Ανοίξτε τη ρίζα του project με έναν απλό τοπικό static server. Για παράδειγμα, αν υπάρχει εγκατεστημένη η Python:

```powershell
python -m http.server 8000
```

Έπειτα επισκεφθείτε το `http://localhost:8000`. Το άνοιγμα του `index.html` απευθείας ως αρχείο δεν αρκεί: ο φυλλομετρητής πρέπει να μπορεί να φορτώσει τα αρχεία JSON μέσω HTTP.

## Δωρεάν δημοσίευση και CMS

1. Δημιουργήστε δημόσιο repository στο GitHub και ανεβάστε τα αρχεία αυτού του φακέλου. Το GitHub Pages μπορεί να φιλοξενήσει δωρεάν αυτόν τον στατικό ιστότοπο.
2. Στο `admin/config.yml`, αντικαταστήστε τα `YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME`, `YOUR-FREE-OAUTH-SERVICE.example` και `YOUR-SITE-DOMAIN.example` με τα δικά σας στοιχεία.
3. Για σύνδεση του Decap CMS με το GitHub, απαιτείται OAuth provider συμβατός με το Decap CMS. Φιλοξενήστε ένα μικρό OAuth service σε δωρεάν επίπεδο υπηρεσίας, ρυθμίστε το ως GitHub OAuth App με callback URL που παρέχει η υπηρεσία και ορίστε τη διεύθυνσή του ως `backend.base_url`. Μην αποθηκεύσετε client secret σε αυτό το repository ή σε κώδικα του browser. Για τη ρύθμιση του provider ακολουθήστε την επίσημη τεκμηρίωση Decap CMS: <https://decapcms.org/docs/git-backend/#authentication>.
4. Ενεργοποιήστε το GitHub Pages από τις ρυθμίσεις του repository, επιλέγοντας τον κλάδο `main` και τον βασικό φάκελο (`/`). Αν χρησιμοποιήσετε custom domain, ρυθμίστε HTTPS και ενημερώστε το `site_url` και το `display_url`.
5. Ανοίξτε το `https://ΤΟ-DOMAIN-ΣΑΣ/admin/`, συνδεθείτε και δημοσιεύστε αλλαγές. Το CMS δημιουργεί commit στο GitHub· το Pages αναδημοσιεύει αυτόματα την ενημερωμένη στατική ιστοσελίδα.

Η φιλοξενία GitHub Pages και ο κώδικας του Decap CMS είναι δωρεάν. Ο OAuth provider πρέπει να λειτουργεί και να είναι ρυθμισμένος για να συνδέονται οι διαχειριστές· επιλέξτε δωρεάν πακέτο και ελέγξτε τα όρια/τους όρους του πριν από την εγκατάσταση. Το CMS φορτώνεται από το unpkg CDN, οπότε η διαχείριση περιεχομένου χρειάζεται σύνδεση στο διαδίκτυο.

## Επεξεργασία περιεχομένου

Από το `/admin/` μπορείτε να ενημερώσετε:

- Την αρχική σελίδα, τις φωτογραφίες και το καλωσόρισμα.
- Τα κείμενα των σελίδων και το ιστορικό των προέδρων.
- Τα νέα, με ημερομηνία, φωτογραφία και κείμενο· εμφανίζονται με χρονολογική σειρά.
- Τα έγγραφα εισαγωγής και τα PDF για λήψη.
- Τις φωτογραφίες των χώρων και τις τρεις ενότητες φωτογραφιών.
- Τα στοιχεία επικοινωνίας, τις ώρες λειτουργίας και τους λογαριασμούς δωρεών.

Οι φωτογραφίες και τα έγγραφα που μεταφορτώνετε αποθηκεύονται στο `assets/uploads/` μαζί με το περιεχόμενο του repository. Η εικόνα αρχικής σελίδας είναι προσωρινή εικονογράφηση· αντικαταστήστε την από το CMS με φωτογραφία του κτιρίου.

## Απόρρητο και προσβασιμότητα

Ο ιστότοπος δεν εγκαθιστά εργαλεία ανάλυσης ή διαφημιστικής παρακολούθησης. Η ενημέρωση cookies εξηγεί ότι η απόκρυψή της αποθηκεύεται τοπικά στη συσκευή, χωρίς cookie. Η ενότητα απορρήτου είναι αφετηρία και όχι νομική γνωμάτευση: πριν από τη δημοσίευση συμπληρώστε τα επίσημα στοιχεία του υπευθύνου και ζητήστε έλεγχο των νομικών κειμένων και των στοιχείων δωρεών από τον αρμόδιο φορέα. Χρησιμοποιήστε κατάλληλο κείμενο εναλλακτικού κειμένου στις φωτογραφίες.
